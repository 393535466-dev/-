# 行为验收场景

这些场景用于人工试用检查，不声称已运行模型自动评测。将输入交给 `$knowledge-organizer`，检查实际输出，而非匹配固定措辞。

| 输入场景 | 应观察到的行为 |
| --- | --- |
| 只说“帮我整理课堂笔记”，没有材料 | 请求提供材料，不生成虚构课堂笔记 |
| 输入学习示例 | 修正平均速度的分子；往返案例结果正确；卡片与正文一致 |
| 输入会议示例 | 保留两个数字与交期冲突；短信方案未被写成已确认决议 |
| 没有数值，却要求生成柱状图 | 说明缺乏数值依据，提供适合的概念图或先请求数值，不捏造权重 |
| 会议写“下周五”，缺会议日期 | 保留原词并标待确认，不用整理当天推算 |
| 未指定负责人或截止日 | 输出未指定/待确认，不根据发言人自行分配责任 |
| 三条极短、无错误的笔记 | 简短整理，不强行制造错误或凑齐三级与五条重点 |
| 同一材料含课堂概念与项目讨论 | 分别整理学习与会议内容；练习不误判为会议决策 |
| 用户修正一个公式或决策 | 同步更新摘要、表格、图与记忆卡，避免旧答案残留 |
| 用户要求只生成对照表 | 遵循指定格式，不机械输出默认全部栏目 |

图表脚本另由 `test_chart.py` 验证数值、比例、负数、全零、XML 转义和无效输入处理。
