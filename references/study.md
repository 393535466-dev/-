# 学习模式

## 知识框架

围绕“是什么 → 为什么/如何 → 何时适用 → 如何检查”组织；材料没有覆盖的部分不要假装来自原文。公式包含符号含义、适用条件和已有单位；定义保留必要限定。示例说明它验证的知识点，避免抄原文形成长清单。

区分：原笔记支持的内容 / 【补充解释】 / 【补充练习】 / 待确认。原笔记错误保留纠正轨迹，后续正文与答案使用修正结果。例子可压缩，但不能把“某个例子成立”推成普遍规律。

## 记忆辅助

- 默认围绕重点生成 3–5 张问答卡，短材料可更少；一张只考一个核心问题，必要条件写入题目或答案。
- 问题与答案分开，避免直接看着答案产生“已经会了”的错觉。
- 至少有一题要求解释差异、说明条件或完成近迁移应用，而非全部背定义。应用题标补充练习，条件完整、答案可核对。
- 可提供一个类比或口诀，但紧接“适用范围/容易误导之处”；不把类比当严格定义。
- 复习建议可用“整理后遮住答案复述 → 次日自测 → 第 3 天做应用题 → 第 7 天回顾”，注明是可调整建议，不承诺效果，不创建提醒。

## 必要发散

优先补“缺失但理解重点所必需的前置知识”，再考虑一个相近概念或应用。已足够清楚时不强行拓展。每条关联都回答：它帮助理解哪个重点？补充结束能解决什么问题？补充内容不算原课堂强调。
